# SmartParkingSystem-DataBase
Simple smart parking system database with some sample data - DBI202.

# Quy tắc làm việc nhóm
- Phải tạo nhánh (branch) riêng của mình khi làm việc
- Không commit thẳng vào main và phải tạo pull request
- Không chỉnh sửa file nằm trong thư mục của người khác hoặc file tổng hợp như Environment, SmartParkingSystem
- Tải tất cả file/folder khi chạy nhưng chỉ chỉnh sửa file trên thư mục của mình
- Khi pull request phải ghi ngày update vào commit title và ghi rõ đã chỉnh sửa gì ở phần description

# Workflow
 1. Download dự án về máy
 2. Tạo branch
 3. Code
 4. Commit vào branch của mình
 5. Tạo pull request             -> member tự thông báo trên group sau khi tạo pull request
 6. Chờ review và merge vào main -> leader thông báo trên group sau khi merge (thường là sau khi mọi người đều đã xong hoặc mỗi ngày 1 lần)
 7. Download lại dự án phiên bản mới nhất về máy (sau khi đã merge và cần làm thêm tính năng mới)
 8. Xóa folder dự án cũ đi (sau khi chắc chắn phiên bản mới đã được tải về)
-> lặp lại toàn bộ
